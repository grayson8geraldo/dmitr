# Deposit Acceleration Trading Bot

Торговый бот для разгона депозита со $100 до $1000 за 2 недели.
Стратегия основана на торговле от ликвидаций с жёстким риск-менеджментом.

## Стратегия

### Риск-менеджмент
- **Кросс-маржа** + **Режим хеджирования** (одновременно лонг и шорт)
- Вход в сделку: **5-10% от депозита**
- Плечо: **10x** (при $50 позиции используется только $5 маржи)
- Риск на сделку: **0.5% от депозита**
- Соотношение риск/прибыль: **1:3**
- Максимальный дневной убыток: **3%** → бот останавливается

### Точки входа (от ликвидаций)
- **Шорт**: после пампа, когда ликвидированы шортисты, OI падает, CVD показывает продажи
- **Лонг**: после дампа, когда ликвидированы лонгисты, CVD показывает покупки, первый отскок

### Быстрые сделки
- Тейк-профит: **5% движения цены**
- Стоп-лосс: **~1.67%** (для RR 1:3)
- Целевой винрейт: **80%** (8 из 10 сделок в плюс)

### Спасение позиций
- **Усреднение**: только на значимых уровнях (10-15% хода), тем же объёмом монет
- **Хеджирование**: при убытке 8%+ и отрицательном фандинге → открытие противоположной позиции

## Установка

```bash
# Клонировать репозиторий
git clone <repo-url>
cd dmitr

# Установить зависимости
pip install -r requirements.txt

# Настроить API ключи
cp .env.example .env
# Отредактировать .env — вписать ключи от биржи и CoinGlass
```

## Запуск

```bash
# Тестнет (безопасно, без реальных денег)
python main.py

# Показать конфигурацию и прогноз роста
python main.py --status

# Боевой режим (РЕАЛЬНЫЕ ДЕНЬГИ!)
python main.py --live

# С подробным логированием
python main.py --log-level DEBUG
```

## Архитектура

```
├── main.py                  # Точка входа, главный цикл
├── config.py                # Все настройки стратегии
├── bot/
│   ├── risk_manager.py      # Риск-менеджмент, расчёт позиций
│   ├── market_analyzer.py   # Анализ рынка (ликвидации, OI, CVD)
│   ├── position_manager.py  # Управление позициями, усреднение, хедж
│   ├── exchange_connector.py # Подключение к бирже (CCXT)
│   └── strategy.py          # Торговая логика
├── requirements.txt
└── .env.example
```

## Поддерживаемые биржи

## Важно

- Начинайте с **тестнета** (`python main.py` без `--live`)
- Бот НЕ гарантирует прибыль — криптовалютная торговля сопряжена с высоким риском
- Не инвестируйте средства, которые не можете позволить себе потерять
- Настройки по умолчанию оптимизированы для данной стратегии, но рынок непредсказуем
